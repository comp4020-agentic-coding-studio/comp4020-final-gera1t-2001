# Crit 8 reflection

## What was the breakthrough that moved the work forward?

I did not build a particularly meaningful feature this week. I have not
worked out what my website will be yet, so I feel a bit embarrassed: all I
built was a login system.

But there was one real turn. A password on its own is not safe enough: if you
forget it, you cannot even reset it. So I chose security questions as a
second safeguard. I used security questions because they are a classic
design that needs no email address or phone number. Then the first version
the AI produced let users write their own security questions, which honestly
threw me. That was crazy. Only by using the app myself did I see it, and I
changed it to questions picked from a fixed list, with a stronger password
rule as well.

## What did this work change about who I want to be as a software developer?

What was different from earlier weeks is that this one asked us to read more.
Reading, I realised that before AI, writing code was hard, tiring work. Now
that AI is here, anyone can become a developer. But someone who only uses AI,
without the knowledge behind it, is like a cook who can only make dishes that
look delicious but do not actually taste good.
